# Return the vector of 990-only financial field names (PC scope)

Returns financial fields that appear only on the full Form 990 (Parts
VIII, IX, and X). These fields are not present on the 990-EZ. Used by
[`sanitize_financials()`](https://nonprofit-open-data-collective.github.io/fiscal/reference/sanitize_financials.md)
to restrict zero-imputation to full 990 filers.

## Usage

``` r
get_pc_fields()
```

## Value

A character vector of column names.
