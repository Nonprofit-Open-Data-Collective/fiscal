H4: Does Earned Revenue Replace Fundraising?

Pre-specified cross-section, plus the COVID earned-revenue shock

  • Purpose
  • 1. Pre-specification (test A)
  • 2. Data
  • 3. Test A: the pre-specified cross-section
  • 4. Test B: the COVID earned-revenue shock (exploratory)
  • 5. Findings

Purpose

H4 from the ratio-correlation memo: organizations that earn their revenue spend less on raising it. The correlation that motivated it is self_suff x fundr_exp = -0.21, which is -0.24 beyond the conditional construction null, one of the few relationships in the 14-ratio set that survives that benchmark.

Two tests:

  • A. Pre-specified cross-section. Fundraising expense on program service revenue, holding contributions and size. Written in the memo before estimation and repeated below unchanged.
  • B. The COVID shock (exploratory). Program service revenue fell from 16.5% of revenue in 2019 to 10.6% in 2020 and recovered by 2023. If earned revenue and fundraising are substitutes, organizations that lost the most earned revenue should have raised fundraising effort afterwards. This design was not pre-specified; it is labeled exploratory throughout.

1. Pre-specification (test A)

Outcome Coefficient that carries the test Support if Reject if
Any fundraising expense; log fundraising expense log program service revenue, holding log contributions and size < 0 in both parts, with the contributions coefficient > 0 >= 0
  • Sample. Pooled tax years 2022 and 2023, December year-ends, organizations that filed a full 990 every year 2019-2023.
  • Models. Linear probability model for any fundraising expense; OLS on log fundraising expense among filers reporting a positive amount. Predictors enter as log(1 + x) plus an indicator for x > 0. Size controls: 4-df natural splines of log expenses and log(1 + total assets).
  • Evidence rule. Same as H1-H3: the estimate must have the predicted sign and lie beyond the 0.5th or 99.5th percentile of 200 refits in which the program-revenue block is shuffled within cells of expenses x assets per dollar of expenses.

3. Test A: the pre-specified cross-section

size_cells <- function(E, A, bins = 20) {
  eb <- cut(rank(E, ties.method = "first"), bins, labels = FALSE)
  ab <- ave(A / E, eb, FUN = function(z) cut(rank(z, ties.method = "first"), bins, labels = FALSE))
  (eb - 1) * bins + ab
}
permute_within <- function(cells) {
  n <- length(cells); p <- integer(n)
  p[order(cells, seq_len(n))] <- order(cells, runif(n))
  p
}
robust_fit <- function(y, W) {
  XtXi <- solve(crossprod(W))
  b <- drop(XtXi %*% crossprod(W, y))
  e <- drop(y - W %*% b)
  V <- XtXi %*% crossprod(W * e) %*% XtXi * nrow(W) / (nrow(W) - ncol(W))
  data.frame(term = colnames(W), estimate = b, se = sqrt(diag(V)), row.names = NULL)
}
# Coefficient on the first column of a block, everything else held fixed (FWL).
perm_block <- function(block, others, models, cells, B) {
  prep <- lapply(models, function(md) {
    q <- qr(others[md$rows, , drop = FALSE]); list(q = q, ry = qr.resid(q, md$y))
  })
  coef_for <- function(Bf) sapply(names(models), function(nm) {
    R <- qr.resid(prep[[nm]]$q, Bf[models[[nm]]$rows, , drop = FALSE])
    solve(crossprod(R), crossprod(R, prep[[nm]]$ry))[1]
  })
  list(observed = coef_for(block),
       perms = do.call(rbind, lapply(seq_len(B), function(i)
         coef_for(block[permute_within(cells), , drop = FALSE]))))
}

4. Test B: the COVID earned-revenue shock (exploratory)

If the two are substitutes, an organization that lost earned revenue in the pandemic should have leaned harder on fundraising afterwards. The shock is the change in program revenue from 2019 to 2021; the response is the change in fundraising expense from 2019 to 2023. Both are log changes. Subsector fixed effects absorb the fact that the shock hit arts, education, and health differently, and the 2019 levels of fundraising and contributions allow for mean reversion.

5. Findings

  • Cross-section. The program-revenue coefficient is -0.0366 for having any fundraising expense and -0.0621 for the amount, against shuffle bounds of -0.0020 and -0.0067. The contributions coefficients are 0.0693 and 0.2800. The pre-specified verdict is supported.
  • Within organizations. A 1-unit change in log program revenue goes with a 0.0143 change in log fundraising expense.
  • The shock. A one-standard-deviation loss of earned revenue between 2019 and 2021 is followed by a -0.012 change in log fundraising expense by 2023 (coefficient 0.0054, SE 0.0050); a negative coefficient means substitution.
