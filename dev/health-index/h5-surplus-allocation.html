H5: Where Does a Surplus Go?

Allocation of the annual surplus across the balance sheet, 2019-2023

  • Purpose

Purpose

H5 from the ratio-correlation memo: a surplus has to go somewhere. Every dollar of revenue not spent ends the year as more cash, more receivables, more property, more investments, or less debt. This document estimates that split.

The accounting identity is the check on the estimates. Writing the year’s change in each balance-sheet block as a share of the same denominator, the asset-side coefficients minus the liability-side coefficients must equal the coefficient for the change in net assets, and that in turn should be close to 1 if the surplus is what drives net assets.

Unlike H1-H3, this hypothesis makes no prediction about which component wins. The split itself is the estimate.

Window. Pooled tax years 2022 and 2023, December year-ends, organizations that filed a full 990 in every year 2019-2023. Tax years 2020 and 2021 are excluded from the main estimate: relief funding pushed the median surplus margin to 0.113 in 2021 against 0.027 in 2023, and median cash from 5.1 to 7.6 months. 2019 and 2021 are estimated separately as contrasts.

A surplus is not the only thing that moves net assets: unrealized investment gains, prior-period adjustments, and donated capital also land there. The regression below estimates how much of the surplus is traceable, not whether net assets equal the surplus.

3. The allocation regressions

Every quantity is divided by the year’s total expenses, so a coefficient reads as “cents of each surplus dollar”.

Outliers are handled by dropping rows, not by clipping values. Winsorizing each component separately would break the very identity this test relies on: the clipped parts no longer sum to the clipped total, and the coefficients stop adding up. (A first version of this document did exactly that, and the identity check caught it.) Instead, organization-years outside the 1st/99th percentile of the surplus ratio or of the change in total assets are dropped, within year. Whatever survives keeps its raw values, so the blocks still add up and OLS coefficients add up with them.

Standard errors are HC1. Each row is one organization-year, and the pooled window holds two years per organization, so the robustness section repeats the estimate with organization fixed effects.

SCALED <- c("surplus", "d_cash", "d_other_current", "d_fixed", "d_other_assets",
            "d_lt", "d_st", "d_other_liab", "d_assets", "d_liab", "d_na",
            "contributions", "program_revenue", "investment_income", "gains_on_sales",
            "other_revenue", "program_expenses", "admin_expenses", "fundraising_expenses",
            "unallocated_expenses")

scale_vars <- function(z, trim = TRUE) {
  out <- copy(z)
  for (v in SCALED) out[[v]] <- out[[v]] / out$E
  if (!trim) return(out)
  # `:=` by group assigns back to the right rows; a grouped select would return
  # the flags in group order and misalign them when years are interleaved.
  out[, keep := {
    qs <- quantile(surplus, c(0.01, 0.99), na.rm = TRUE)
    qa <- quantile(d_assets, c(0.01, 0.99), na.rm = TRUE)
    surplus >= qs[[1]] & surplus <= qs[[2]] & d_assets >= qa[[1]] & d_assets <= qa[[2]]
  }, by = year]
  out <- out[keep == TRUE]
  out[, keep := NULL]
  out[]
}

ols <- function(y, W) {
  XtXi <- solve(crossprod(W))
  bhat <- drop(XtXi %*% crossprod(W, y))
  res <- drop(y - W %*% bhat)
  V <- XtXi %*% crossprod(W * res) %*% XtXi * nrow(W) / (nrow(W) - ncol(W))
  list(b = bhat, se = sqrt(diag(V)))
}

BLOCKS <- c(cash = "d_cash", other_current_assets = "d_other_current", fixed_assets = "d_fixed",
            other_assets = "d_other_assets", long_term_debt = "d_lt",
            short_term_liabilities = "d_st", other_liabilities = "d_other_liab")

allocate <- function(z, label, trim = TRUE) {
  s <- scale_vars(z, trim = trim)
  W <- cbind(intercept = 1, surplus = s$surplus)
  out <- rbindlist(lapply(names(BLOCKS), function(nm) {
    f <- ols(s[[BLOCKS[[nm]]]], W)
    data.table(window = label, block = nm, cents_per_surplus_dollar = f$b[["surplus"]],
               se = f$se[["surplus"]])
  }))
  side <- c(cash = 1, other_current_assets = 1, fixed_assets = 1, other_assets = 1,
            long_term_debt = -1, short_term_liabilities = -1, other_liabilities = -1)
  out[, side := ifelse(side[block] > 0, "asset", "liability")]
  attr(out, "identity") <- data.table(
    window = label,
    assets_minus_liabilities = sum(out$cents_per_surplus_dollar * side[out$block]),
    net_assets_direct = ols(s$d_na, W)$b[["surplus"]],
    n = nrow(s))
  out
}

5. Where the surplus comes from

The allocation above answers where a surplus goes. The same sample answers where it comes from, in the same units. Because the surplus is revenue minus expenses, and both are sums of reported lines, the covariance of each line with the surplus, divided by the variance of the surplus, gives shares that add to exactly 1. A share of 0.64 for contributions means that of a one-dollar difference in surplus, 64 cents co-move with contributions.

The two sides are not symmetric. Surpluses arrive mostly as contributions and investment returns, and they leave mostly as cash and investments. Property absorbs a seventh, and debt repayment a smaller share still.

6. Findings

  • Traceable share. The asset-side minus liability-side coefficients sum to 0.985, against 0.985 from regressing the change in net assets directly on the surplus. The identity holds in the estimates.
  • Cash. 0.371 of each surplus dollar ends the year as cash.
  • Property. 0.139 goes into land, buildings, and equipment.
  • Other assets. 0.320, mostly investments.
  • Debt. Long-term debt changes by -0.021 and short-term liabilities by -0.010 per surplus dollar; negative coefficients mean surpluses coincide with paying debt down.
