Should Reserves and Performance Carry Separate Weight?

Accumulation, overlap, and incremental validity of the health dimensions

  • The question

  • 2. Overlap between the dimensions

The question

H5 showed that about 69 cents of every surplus dollar ends the year in cash or investments. Reserves are therefore largely the running total of past performance. fiscal_weights() weights dimensions equally by default, so an index that scores reserves and performance separately counts the same history twice: once as the stock, once as this year’s increment to it.

Three things decide whether that is a problem:

  1. Accumulation. How much of today’s reserves is explained by past reserves plus the surpluses since?
  2. Overlap. How correlated are the dimension scores in a given year?
  3. Incremental validity. Does performance predict later trouble beyond reserves, and does reserves predict beyond performance? Weights should follow the answer, not the count of dimensions.

year_scores <- function(y) {
  built <- build_ratio_frame(d[TAX_YEAR == y], seed = params$seed)
  z <- as.data.frame(lapply(built$frame[unlist(MEMBERS)], winsor_normalize))
  out <- data.table(EIN2 = built$ein, year = y)
  for (nm in names(MEMBERS)) {
    s <- rowMeans(z[, MEMBERS[[nm]], drop = FALSE])
    out[[nm]] <- as.numeric(scale(if (nm == "leverage") -s else s))
  }
  k <- built$components
  out[, `:=`(surplus_per_expense = (k$R - k$E) / k$E, E = k$E, A = k$A,
             cash_months = 12 * (k$cash + k$recv) / pmax(k$E, 1))]
  out[]
}

3. Accumulation: is reserves the running total?

ols <- function(y, W) {
  XtXi <- solve(crossprod(W)); b <- drop(XtXi %*% crossprod(W, y))
  e <- drop(y - W %*% b)
  V <- XtXi %*% crossprod(W * e) %*% XtXi * nrow(W) / (nrow(W) - ncol(W))
  list(coef = data.table(term = colnames(W), estimate = b, se = sqrt(diag(V))),
       fitted = drop(W %*% b), r2 = 1 - var(e) / var(y))
}
wz <- function(x) { q <- quantile(x, c(0.01, 0.99), na.rm = TRUE)
                    as.numeric(scale(pmin(pmax(x, q[[1]]), q[[2]]))) }

4. Incremental validity

Scores are measured in 2021 and used to predict 2022-2023. The question for weighting is not whether each dimension predicts on its own, but how much each adds to the others.

auc <- function(score, y) {
  r <- rank(score); n1 <- as.numeric(sum(y == 1)); n0 <- as.numeric(sum(y == 0))
  (sum(r[y == 1]) - n1 * (n1 + 1) / 2) / (n1 * n0)
}
ctrl <- cbind(intercept = 1, ns(log(pmax(m$E, 1)), df = 4))
OUT <- c(both_years_deficit = "both_years_deficit", any_deficit = "any_deficit",
         na_fell = "na_fell", cash_fell_month = "cash_fell_month", no2024 = "no2024")
race <- rbindlist(lapply(names(OUT), function(nm) {
  y <- m[[OUT[[nm]]]]
  fit <- function(cols) {
    W <- if (length(cols)) cbind(ctrl, as.matrix(m[, ..cols])) else ctrl
    f <- ols(y, W); list(auc = auc(f$fitted, y), coef = f$coef)
  }
  base <- fit(character()); res <- fit("reserves"); per <- fit("performance")
  lev <- fit("leverage"); all3 <- fit(c("reserves", "performance", "leverage"))
  cf <- all3$coef

             auc_size_only = base$auc, auc_reserves = res$auc, auc_performance = per$auc,

             gain_reserves_over_performance = all3$auc - fit(c("performance", "leverage"))$auc,
             beta_reserves = cf[term == "reserves", estimate],
             beta_performance = cf[term == "performance", estimate],

}))

5. Implied weights

If weights should track how much each dimension contributes to predicting trouble, one defensible rule is to set them proportional to each dimension’s incremental AUC, averaged across outcomes, rather than to give each an equal share.

gains <- rbindlist(lapply(names(OUT), function(nm) {
  y <- m[[OUT[[nm]]]]
  fit_auc <- function(cols) {
    W <- if (length(cols)) cbind(ctrl, as.matrix(m[, ..cols])) else ctrl
    auc(ols(y, W)$fitted, y)
  }
  all3 <- fit_auc(c("reserves", "performance", "leverage"))
  data.table(outcome = nm,
             reserves = all3 - fit_auc(c("performance", "leverage")),
             performance = all3 - fit_auc(c("reserves", "leverage")),
             leverage = all3 - fit_auc(c("reserves", "performance")))
}))
avg <- colMeans(gains[, .(reserves, performance, leverage)])
