Does the Matching Gap Predict Anything?

Panel validation of the long-term matching gap, 2019 to 2023

  • Purpose
  • 1. Sample and gaps
  • 2. Outcomes, 2020-2023
  • 3. Does the 2019 gap predict 2020-2023?
  • 4. Findings

Purpose

matching-gap-2023.Rmd built an indicator from the H1 and H2 benchmarks: debt beyond what an organization’s asset mix and size support. Validated inside a single filing, it added almost nothing. The one strong result, cash drawdowns, turned out to be a floor effect, and the long-term gap added at most 0.003 AUC for deficits and net-asset declines.

That test had three weaknesses the panel fixes:

  • A one-year horizon. Financial distress plays out over years.
  • Outcomes measured inside the same filing, so a gap measured at the start of the year predicted events already partly under way.
  • No way to ask whether the gap is a passing condition or a standing trait.

Here the gap is measured in 2019 and used to predict 2020-2023. Three changes follow the recommendations from the memo: the Poisson benchmark instead of the two-part model, scaling by expenses as well as by assets, and controls for starting cash and asset intensity from the outset.

1. Sample and gaps

The sample is organizations that filed a full 990 with a December year-end in every year 2019-2023. The benchmark is refit within each year, so a gap is always relative to peers of the same size and asset mix in that same year.

d <- as.data.table(readRDS(params$panel_file))

gaps_for_year <- function(year) {
  m <- gap_lines(d[TAX_YEAR == year], "EOY")
  m <- m[m$E > 0 & m$A > 0, ]
  g <- matching_gap(m, type = "ppml")$gaps
  data.table(EIN2 = m$ein, year = year,
             gap_assets = g$gap_long,                       # scaled by total assets
             gap_expenses = (m$lt - g$pred_long) / m$E,     # scaled by expenses
             debt_assets = m$L / m$A, lt = m$lt, A = m$A, E = m$E,
             cash_months = 12 * m$cash / m$E, assets_exp = m$A / m$E)
}

Is the gap a condition or a trait? If an organization’s gap in 2019 tells you its gap in 2023, the indicator is describing a standing financing posture rather than a passing strain.

3. Does the 2019 gap predict 2020-2023?

Each outcome is regressed on the 2019 gap, with debt_assets, size, starting cash months, and asset intensity held fixed. Gaps and debt_assets are winsorized at 1/99 and standardized, so coefficients are per standard deviation. The comparison of interest is a model with the gap against the same model without it.

wz <- function(x) { q <- quantile(x, c(0.01, 0.99), na.rm = TRUE); as.numeric(scale(pmin(pmax(x, q[[1]]), q[[2]]))) }
m <- merge(out, g19[, .(EIN2, gap_assets, gap_expenses, debt_assets, E, A, cash_months, assets_exp)],
           by = "EIN2")
m[, `:=`(z_gap_assets = wz(gap_assets), z_gap_expenses = wz(gap_expenses),
         z_debt_assets = wz(debt_assets))]
controls <- cbind(intercept = 1,
                  ns(log(m$E), df = 4), ns(log1p(m$A), df = 4),
                  ns(log1p(pmax(m$cash_months, 0)), df = 4), ns(log(pmax(m$assets_exp, 0.01)), df = 4))
colnames(controls) <- c("intercept", paste0("size_E", 1:4), paste0("size_A", 1:4),
                        paste0("cash_months", 1:4), paste0("asset_intensity", 1:4))

ols <- function(y, W) {
  XtXi <- solve(crossprod(W)); b <- drop(XtXi %*% crossprod(W, y))
  e <- drop(y - W %*% b)
  V <- XtXi %*% crossprod(W * e) %*% XtXi * nrow(W) / (nrow(W) - ncol(W))
  list(coef = data.frame(term = colnames(W), estimate = b, se = sqrt(diag(V)), row.names = NULL),
       fitted = drop(W %*% b))
}
auc <- function(score, y) {
  r <- rank(score); n1 <- as.numeric(sum(y == 1)); n0 <- as.numeric(sum(y == 0))
  (sum(r[y == 1]) - n1 * (n1 + 1) / 2) / (n1 * n0)
}

Is the relationship linear? The quintile table below suggests both tails carry risk: organizations far above the benchmark are over-borrowed, and those far below it tend to have thin balance sheets relative to their spending. A linear term averages the two away. These models add quintile dummies for the gap, and separately its absolute deviation from the median.

qgap <- cut(rank(m$gap_expenses, ties.method = "first"), 5, labels = FALSE)
qd <- model.matrix(~ factor(qgap))[, -1, drop = FALSE]
colnames(qd) <- paste0("gap_q", 2:5)
absdev <- wz(abs(m$gap_expenses - median(m$gap_expenses)))

nonlinear <- rbindlist(lapply(c("three_plus_deficits", "na_fell", "no2024"), function(nm) {

4. Findings

  • Persistence. The gap is highly persistent, which makes it a standing financing posture more than a passing strain.
  • Prediction. The largest AUC gain from adding the gap to a model that already has debt_assets, size, cash months, and asset intensity is 0.0005.
  • Direction. Coefficients per standard deviation appear in the tables above; a positive value means a larger gap goes with a worse outcome.
