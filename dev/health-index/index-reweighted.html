Reweighting the Fiscal Health Index

How much do scores and rankings move when weights follow predictive value?

  • Purpose
  • 1. Scores and index versions
  • 2. How much do rankings move?
  • 3. Does the reweighted index predict better?
  • 4. Findings

Purpose

dimension-weighting.Rmd found that reserves and performance predict different outcomes, that leverage predicts none of them, and that weights proportional to incremental AUC would be about 0.59 performance and 0.41 reserves rather than a third each. This document rebuilds the index under those weights and asks the practical question: who moves, and does the reweighted score predict better?

Three schemes, all over the same dimension scores:

Scheme Reserves Performance Leverage
Equal (current default) 1/3 1/3 1/3
Incremental AUC 0.41 0.59 0
Incremental AUC, excluding the cash outcome 0.12 0.88 0

The third scheme drops the cash-drawdown outcome from the weighting exercise, because an organization can only lose a month of cash if it had one, which flatters reserves. It is shown as a sensitivity, not a recommendation.

Note on the package default: fiscal_weights(include_standalone = TRUE) also gives equal weight to the standalone measures, so the shipped default would spread weight across six measures, not three. The comparison here is against the three-dimension version recommended in dimension-discovery-2023.Rmd.

3. Does the reweighted index predict better?

The index is rebuilt on 2021 scores and used to predict 2022-2023, the same outcomes as the weighting analysis.

s21 <- dimension_scores(d[TAX_YEAR == 2021], seed = params$seed)
for (nm in names(WEIGHTS)) s21[[paste0("index_", nm)]] <- composite_index(s21, WEIGHTS[[nm]])

flows <- d[TAX_YEAR %in% 2021:2023, .(EIN2, year = TAX_YEAR,
                                      R = as.numeric(F9_08_REV_TOT_TOT),
                                      E = as.numeric(F9_09_EXP_TOT_TOT),
                                      na = as.numeric(F9_10_NAFB_TOT_EOY),
                                      cash = as.numeric(F9_10_ASSET_CASH_EOY) +
                                             as.numeric(F9_10_ASSET_SAVING_EOY))]
for (cl in c("R", "E", "na", "cash")) flows[[cl]][is.na(flows[[cl]])] <- 0
o <- dcast(flows, EIN2 ~ year, value.var = c("R", "E", "na", "cash"))
setnames(o, gsub("_(\\d{4})$", "\\1", names(o)))
o <- o[complete.cases(o)]
o[, `:=`(both_years_deficit = as.numeric(R2022 < E2022 & R2023 < E2023),
         any_deficit = as.numeric(R2022 < E2022 | R2023 < E2023),
         na_fell = as.numeric(na2023 < na2021),
         cash_fell_month = as.numeric(12 * (cash2023 - cash2021) / pmax(E2021, 1) < -1),
         no2024 = as.numeric(!(EIN2 %chin% in2024)))]
m <- merge(o, s21[, c("EIN2", idx, "E"), with = FALSE], by = "EIN2")

auc <- function(score, y) {
  r <- rank(score); n1 <- as.numeric(sum(y == 1)); n0 <- as.numeric(sum(y == 0))
  (sum(r[y == 1]) - n1 * (n1 + 1) / 2) / (n1 * n0)
}
OUT <- c("both_years_deficit", "any_deficit", "na_fell", "cash_fell_month", "no2024")
val <- rbindlist(lapply(OUT, function(nm) {
  y <- m[[nm]]
  # a low index should mean trouble, so AUC is computed on the reversed score
  data.table(outcome = nm, rate = mean(y),
             equal = auc(-m$index_equal, y),
             incremental = auc(-m$index_incremental, y),
             performance_dominant = auc(-m$index_performance_dominant, y))
}))
val[, `:=`(gain_incremental = incremental - equal,
           gain_performance_dominant = performance_dominant - equal)]
kable(val, digits = 4, caption = "AUC of each index version (2021 index, 2022-2023 outcomes)")

4. Findings

  • Rankings move less than the weights do. The equal-weighted and incremental-weighted indices correlate at 0.876 (Spearman), and 64.1% of organizations change at least one decile.
  • Prediction improves where performance matters and is unchanged or worse for the cash outcome; the table in section 3 gives the sizes.
  • The bottom decile catches more distress under the reweighted index, which is the number that matters for triage.
