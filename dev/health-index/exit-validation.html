Does the Index Predict Failure?

Multi-year filing gaps among 2019 full-990 filers

  • Purpose
  • 1. Filing patterns after 2019
  • 2. 2019 scores for the cohort
  • 3. Does the index predict the gap?
  • 4. Findings

Purpose

Every validation so far used a panel that required a filing in all of 2019-2023, which removed exactly the organizations a failure test needs. This document uses the cohort panel built by dev/panel/panel_build_exits.R: all 280,158 organizations that filed a full 990 for tax year 2019, followed through 2024 whether or not they kept filing. A gap is the outcome.

What a filing gap is and is not. Disappearing from the e-file record can mean dissolution, a merger, or shrinking below the 990 threshold and moving to the 990-N postcard, which is not in these files. It can also mean a late filing. The outcomes below are therefore “stopped filing a 990 or 990EZ”, not “failed”, and the 2024 file is still incomplete. Reading a gap as failure is safest for larger organizations, which rarely drop to 990-N.

3. Does the index predict the gap?

ols <- function(y, W) {
  XtXi <- solve(crossprod(W)); b <- drop(XtXi %*% crossprod(W, y))
  e <- drop(y - W %*% b)
  V <- XtXi %*% crossprod(W * e) %*% XtXi * nrow(W) / (nrow(W) - ncol(W))
  list(coef = data.table(term = colnames(W), estimate = b, se = sqrt(diag(V))),
       fitted = drop(W %*% b))
}
auc <- function(score, y) {
  r <- rank(score); n1 <- as.numeric(sum(y == 1)); n0 <- as.numeric(sum(y == 0))
  (sum(r[y == 1]) - n1 * (n1 + 1) / 2) / (n1 * n0)
}
ctrl <- cbind(intercept = 1, ns(log(pmax(m$E, 1)), df = 4))

OUT <- c(gap_2022_2023 = "gap_2022_2023", gap_confirmed = "gap_confirmed",
         gap_from_2021 = "gap_from_2021", downshift_ez = "downshift_ez")
race <- rbindlist(lapply(names(OUT), function(nm) {
  y <- m[[OUT[[nm]]]]
  fit <- function(cols) {
    W <- if (length(cols)) cbind(ctrl, as.matrix(m[, ..cols])) else ctrl
    f <- ols(y, W); list(auc = auc(f$fitted, y), coef = f$coef)
  }
  all3 <- fit(c("reserves", "performance", "leverage"))
  cf <- all3$coef
  data.table(outcome = nm, rate = mean(y),
             auc_size_only = fit(character())$auc,
             auc_reserves = fit("reserves")$auc,
             auc_performance = fit("performance")$auc,
             auc_leverage = fit("leverage")$auc,
             auc_all_three = all3$auc,
             beta_reserves = cf[term == "reserves", estimate],
             beta_performance = cf[term == "performance", estimate],
             beta_leverage = cf[term == "leverage", estimate])
}))

4. Findings

  • Base rate. 5.35% of 2019 full-990 filers had no filing in 2022, 2023, or 2024.
  • Dimensions. Size alone gives AUC 0.662; adding all three dimensions gives 0.715.
  • Index versions. Raw AUC is 0.553 for equal weights and 0.587 for incremental weights.
